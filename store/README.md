# Plazo – store graphics

| File | Use |
|---|---|
| `icon.svg` | Master icon (vector). The game uses it as `game/icon.svg`. |
| `icon-512.png` | Google Play "App icon" (512 x 512). |
| `feature-graphic-1024x500.png` | Google Play "Feature graphic" (1024 x 500). |
| `icon-alternative-b.svg` | Second design (a "P" made of blocks) if you prefer it. |
| `icon-options.png` | Both designs side by side, big and at phone size. |

Android launcher icons (adaptive: foreground + background, and the legacy
192 px icon) are in `game/icons/` and set in `game/export_presets.cfg`.
