# الفروق بين Roobox و Roblox — قائمة التطوير

هاي القائمة الكاملة لكل ميزة موجودة بروبلوكس (التطبيق + الألعاب + Studio + المنصة)
ووين وصلنا فيها. منحدّثها مع كل نسخة.
(القصد إنو نوصل لنفس *القدرات* بطريقتنا — بدون نسخ أسماء أو رسومات أو شخصيات روبلوكس.)

**الحالة:** ✅ موجود — 🟡 موجود جزئياً — ❌ ناقص
**الأولوية:** P1 = للإطلاق الأول — P2 = بعد الإطلاق بفترة قصيرة — P3 = لاحقاً

آخر تحديث: v0.20
